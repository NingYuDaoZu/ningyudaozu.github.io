你好，我是凝雨道祖

开发者 / 折腾爱好者 / 间歇性写作者

我是一个喜欢折腾技术的人，白天写代码，晚上偶尔也写点东西。这个博客是我的自留地， 用来放技术实践、学习笔记，以及一些不成体系的生活观察。

我不太追求更新频率，也不打算把它做成一个「内容产品」。对我来说，写作更像是把脑子里 乱糟糟的东西整理一遍——写完之后，自己想得更清楚了，这就够了。如果恰好还能帮到别人，那就更好。

关于内容

大概会写这几类东西：

  • 技术笔记 —— 踩过的坑、验证过的方案、值得复用的代码。
  • 折腾记录 —— 搭个网站、换个工具、折腾硬件之类的全过程。
  • 读书与思考 —— 看到的书、文章，和它们让我想到的事。
  • 生活碎碎念 —— 频率最低，但偶尔会有。

关于这个站点

站点本身是纯静态的 HTML + CSS + 少量 JavaScript，托管在 GitHub Pages 上，没有数据库， 也没有统计脚本。你想看什么就看什么，我这边不会知道你来过。

如何订阅

如果你用 RSS 阅读器，可以直接订阅 feed.xml。不想用 RSS 的话，偶尔来看看也行。

联系我

有想聊的，或者发现哪里写错了，欢迎来 GitHub 上找我：
